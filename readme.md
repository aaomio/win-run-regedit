# Windows Registry Editor Troubleshooting

## Overview

This repository contains common Windows troubleshooting scenarios using registry edit.

All fixes are primarily performed using **Registry Editor (regedit)** or supporting tools like PowerShell and Command Prompt.

To access Registry Editor:

- Press **Win + R**
- Type **regedit**
- Press **Enter**
